# Glossário de Git e GitHub

- **Repositório:** espaço que guarda os arquivos e o histórico de um projeto.
- **Commit:** registro de uma alteração, identificado por uma mensagem e um código único.
- **Branch:** linha de trabalho independente, usada para desenvolver uma mudança sem alterar diretamente a branch principal.
- **Merge:** integração das alterações de uma branch em outra.
- **Conflito:** situação em que o Git não consegue combinar automaticamente mudanças incompatíveis no mesmo trecho.
- **Issue:** registro de uma tarefa, dúvida ou problema do projeto.
- **Pull request (PR):** proposta para revisar e integrar mudanças de uma branch em outra.
- **Revisão:** análise do pull request por outras pessoas, com comentários, pedidos de ajuste ou aprovação.
