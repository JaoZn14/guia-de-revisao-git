# Combinados de trabalho

1. Cada mudança deve ser feita em uma branch própria.
2. Commits devem explicar o que foi alterado.
3. Pull requests devem descrever a mudança e referenciar a issue com `Closes #N`.
4. Toda revisão deve ser respeitosa, específica e baseada em critérios do projeto.
5. Quem abriu o pull request não aprova a própria mudança.
6. Resolver conflitos preservando as contribuições válidas de cada branch.
7. Não incluir senhas, tokens, dados pessoais ou outros segredos no repositório.
8. Issues só são fechadas quando seus critérios de conclusão forem atendidos.
